Este es un programa dedicado principalmente a ser un cargador de juegos 
Juegos ejecutables como, Steam, Epic Games, Ports No Oficiales y Emulación.
La aplicación es completamente personalizable a tu gusto, puedes añadir fondos,
añadir musica, y utilizar los 3 temas que están presentes, que son de NSO, XBOX, PLAYSTATION.
